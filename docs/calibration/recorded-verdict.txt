# The M3 rate criterion's last recorded verdict, one line per search dimension.
#
# A campaign run compares itself against the line for its own dimension: a
# volume and a plane are different search spaces (the model's 3σ threshold is
# 4.87σ at 1000² and 5.05σ at 40³), so a rate from one cannot decide the other.
# A run whose dimension has no line creates one only if it is decisive. Within a
# dimension, a result is comparable only when it has at least as many toys.
#
# Update the line in the same commit as the report that changes it; never on its
# own. CI opens an issue when a comparable run moves a verdict.
#
# 2-D: `docs/calibration/lee-2d-3e5.md` — 426 of 300 000 toys on the plane clear
# the model's 4.87σ threshold: rate 1.420e-3, 5% above nominal, Wilson
# [1.291e-3, 1.561e-3] inside the ±20% band, so the criterion is decided and M3's
# box is checked. It replaces the 10⁵ line (128 of 100 000, floor 0.3% short),
# which could not decide.
verdict=PASS toys=300000 dim=2 rate=1.420e-3 low=1.291e-3 high=1.561e-3 threshold=4.87
#
# 3-D: `docs/calibration/lee-3d-40-2e4.md` — 20 000 toys on the 40³ volume, where
# the law holds to 1.02–1.15× from 3σ to 5σ. The rate at the model's own 5.05σ
# threshold is 19% below nominal with an interval from 0.73e-3 to 1.67e-3, so this
# sample cannot decide the 3-D criterion either, and the report's `needs` says it
# would take ~10⁷ toys: it is recorded so that the gate compares a volume against a
# volume, and stays UNDECIDED rather than being closed by the plane's PASS.
verdict=UNDECIDED toys=20000 dim=3 rate=1.100e-3 low=7.266e-4 high=1.665e-3 threshold=5.05
