# LEE calibration — 3-D, 20000 toys

The same bench as the 2-D campaigns, with `UMBRA_LEE_DIM=3`: the scene is `40³`
voxels with one ray along `z` per column (`1600` rays), so every voxel is seen by
exactly one ray as on the plane, and an excursion is a sheet a ray cuts through
rather than a strip it runs along. The side is `40` rather than `1000` because
`1000³` is `10⁹` voxels; the ratios below are what the law is checked on, not the
rates, which belong to a different search space.

Reproduced by `env UMBRA_LEE_DIM=3 UMBRA_LEE_TOYS=20000 UMBRA_LEE_SEED=518447143
UMBRA_LEE_THREADS=16 cargo bench -p umbra-stats --bench lee`. The report below is
that run's output, verbatim.
